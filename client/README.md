# RecipeHub Client

## Overview
This is the frontend for RecipeHub, a polished recipe discovery and sharing application with authentication, dashboards, premium membership entry points, and admin views.

## Tech stack
- React
- Vite
- React Router
- Framer Motion
- Axios
- Lucide React

## Local setup
```bash
npm install
cp .env.example .env
npm run dev
```

## Environment variables
- `VITE_API_URL` - backend API URL

## Build
```bash
npm run build
```

## Deployment
Deploy this client to Vercel or another static host and point `VITE_API_URL` to the live API URL.
